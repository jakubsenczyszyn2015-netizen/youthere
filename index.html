Getting in

Under a minute, start to finish.

  1. Grab the build for your machine from the section above.
  2. Open it. On Windows, double-click the .exe; SmartScreen may call it an unknown publisher, so choose More info → Run anyway. On macOS, unzip and drag YouThere.app to Applications, then right-click it → Open the first time. Neither build is code-signed yet — check the SHA-256 above if you'd rather be sure.
  3. Confirm the server in the little launcher window. Everyone in your group connects to the same one. It's remembered for next time, and a free host can take about 30 seconds to wake up.
  4. Pick a name, then start a party or join one with a code. To uninstall, just delete the file.

Changelog

What changed, most recent first. Also in CHANGELOG.md.

Cross-platform build

2026-08-14 · current download

YouThere? now runs on macOS and Linux, not just Windows. The overlay used to share a process with the app window, and tkinter and the webview toolkit each insist on owning the main thread — fine on Windows, a segfault everywhere else. The overlay now gets a process of its own, which is what makes the other two platforms possible.

  • AddedmacOS build for Apple Silicon, shipped as a YouThere.app bundle.
  • AddedLinux build, distributed over a transfer link because it's too big to host here.
  • AddedFailures now open a window explaining what went wrong instead of quitting silently — including a nudge to install WebKitGTK when that's what Linux is missing.
  • ChangedThe overlay runs as its own process rather than a background thread.

Hosted server

Windows only

Parties moved to a hosted server. The client talks to the YouThere? server online instead of running one on your machine, so a party is visible to everyone wherever they are — not just to people on the same network.

  • AddedYour server address is remembered in ~/.youthere.json, so the launcher pre-fills it next time.
  • AddedThe launcher checks the server is answering before opening the app, and says so when a free host is still waking up.
  • AddedSecure wss:// connections for remote servers; plain ws:// still works for localhost testing.
  • ChangedThe launcher is now a single "which server?" field instead of the old host-or-join screen.
  • ChangedDownload shrank by about 5 MB once the server came out of it.
  • RemovedThe bundled server. No more hosting from your own PC, sharing your LAN IP, or opening firewall ports to get friends in.

Questions

The ones people actually ask.

Why does Windows show a security warning?

The build isn't signed with a paid code-signing certificate, so SmartScreen calls it an unknown publisher. Choose More info → Run anyway. If you want to check the file first, verify its SHA-256 against the hash at the top of this page.

macOS says the app is damaged or from an unidentified developer

Gatekeeper doesn't trust unsigned apps downloaded from the web. Right-click YouThere.app and choose Open, then confirm — you only need to do it once. If macOS still refuses, run xattr -dr com.apple.quarantine /Applications/YouThere.app in Terminal.

Which Macs does it run on?

Apple Silicon only — M1 and later. There's no Intel build yet, so it won't run on older Macs.

Nothing opens on Linux

The app window needs WebKitGTK, which most distros don't ship by default. On Debian and Ubuntu: sudo apt install gir1.2-webkit2-4.0. The app will tell you the same thing in a window if it can't start.

How do I check the SHA-256 hash?

Windows, in PowerShell: Get-FileHash .\YouThere.exe -Algorithm SHA256. macOS or Linux: shasum -a 256 YouThere-mac.zip. It should match the hash on the download card character for character.

Do my friends need to be on my network?

Not anymore. As of the latest build everyone connects to the same hosted server, so a party works across the internet. Just make sure you all type in the same server address.

The launcher is stuck on "Checking…"

Free server hosts go to sleep when nobody's using them and take roughly 30 seconds to wake up. Give it a moment and try Connect again. If it still fails, double-check the address for typos.

Can Windows, Mac and Linux people be in the same party?

Yes. It's the same app on all three, and everyone connects to the same server, so it makes no difference what anyone is running.

How do I uninstall it?

Delete the app — YouThere.exe, or YouThere.app on macOS. There's no installer, so nothing else is left behind apart from ~/.youthere.json, which just remembers your server address.
