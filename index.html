Install in four steps

Under a minute, start to finish.

  1. Download YouThere.exe using the button above.
  2. Move it somewhere sensible — your Desktop or a folder like C:\Apps\YouThere. It runs from wherever it sits.
  3. Double-click to run. On first launch Windows SmartScreen may warn you about an unknown publisher — click More info → Run anyway. That's because the build isn't code-signed yet, not because anything is wrong with it.
  4. Pin it to your taskbar if you'll use it often. To uninstall, just delete the file.

Questions

The ones people actually ask.

Why does Windows show a security warning?

The app isn't signed with a paid code-signing certificate, so SmartScreen flags it as coming from an unknown publisher. Choose More info → Run anyway. You can always verify the download first by checking its SHA-256 against the hash listed at the top of this page.

How do I check the SHA-256 hash?

Open PowerShell in your downloads folder and run Get-FileHash .\YouThere.exe -Algorithm SHA256. The result should match the hash shown in the hero section, character for character.

Is there a Mac or Linux version?

Not right now — this build is Windows 64-bit only. If you'd like one, say so in a GitHub issue so it can be prioritised.

Does it cost anything?

No. It's free to download and free to use.

How do I remove it?

Delete YouThere.exe. There's no installer and no uninstaller, because there's nothing else to clean up.
